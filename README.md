# CardControl DevOps

CardControl es una aplicación web para registrar y consultar información de tarjetas de crédito.

## Funcionalidades
- Registrar tarjetas
- Consultar tarjetas
- Visualizar fechas de corte y pago
- Visualizar saldo actual
- Visualizar pago mínimo
- Visualizar pago para no generar intereses
- Generar logs de operación

## Tecnologías utilizadas
- HTML
- CSS
- JavaScript
- Flask
- MongoDB
- Docker
- Docker Compose
- Bash
- AWS EC2
- AWS S3
- AWS CloudFormation
